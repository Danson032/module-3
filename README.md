# Student Task Manager

As a software engineer, I am continually improving my web development skills by creating practical applications that solve everyday problems. This project allowed me to gain hands-on experience with HTML5, CSS3, and vanilla JavaScript while learning how to build, test, and deploy a web application.

The Student Task Manager is a web application designed to help students organize their academic work. Users can add new tasks, edit existing tasks, mark tasks as completed, and delete tasks they no longer need. The application stores task information locally using browser localStorage, allowing users to access their tasks even after closing and reopening the application.

The purpose of creating this software was to strengthen my understanding of web development, user interface design, state management, and local data persistence.
