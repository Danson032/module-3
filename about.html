What is Student Task Manager?

Student Task Manager is a lightweight, browser-based application designed to help college and university students organize, track, and manage their academic workload. Whether you're juggling multiple courses, managing assignments, projects, exams, and quizzes, this tool provides a simple yet powerful solution to stay organized.

Key Features

  • 📊 Dashboard: View comprehensive statistics about your tasks at a glance
  • ➕ Add Tasks: Easily create new tasks with priority, category, and due dates
  • ✏️ Edit Tasks: Modify existing tasks whenever your plans change
  • 🔍 Search: Find tasks quickly by title, course, or description
  • 🔽 Filter & Sort: Organize tasks by status, priority, category, or date
  • 💾 Local Storage: All data is saved locally on your device - no account needed
  • 📱 Responsive Design: Works seamlessly on desktop, tablet, and mobile devices
  • ✅ Task Completion: Mark tasks as complete and track your progress

How to Use

1. Navigate to Dashboard

View your overall task statistics and upcoming assignments at a glance.

2. Add a New Task

Go to the Tasks page and fill out the form with task details including title, course, priority, category, and due date.

3. Search and Filter

Use the search bar to find specific tasks, or filter by status, priority, or category.

4. Manage Tasks

Edit or delete tasks as needed. Mark tasks as completed when you finish them.

5. Track Progress

Monitor your completion rate and stay on top of upcoming deadlines.

Technology Stack

This application is built using modern web technologies:

  • HTML5: Semantic markup for accessibility
  • CSS3: Modern styling with responsive design
  • Vanilla JavaScript: Pure JavaScript with no frameworks
  • LocalStorage API: Browser-based data persistence

Data Storage

All your tasks are stored locally in your browser using the LocalStorage API. This means:

  • ✓ No server or account needed
  • ✓ Your data is completely private
  • ✓ Data persists between browser sessions
  • ✓ Works offline
  • ⚠️ Data is stored only on this device and browser

Browser Compatibility

Student Task Manager works on all modern browsers that support HTML5, CSS3, and JavaScript:

  • ✓ Chrome/Chromium
  • ✓ Firefox
  • ✓ Safari
  • ✓ Edge
  • ✓ Mobile browsers (iOS Safari, Chrome Mobile)

Sample Data

On the Dashboard page, you can load sample tasks to see how the application works. This is perfect for exploring the features without manually creating tasks. You can clear all sample data at any time.

Privacy & Security

Your privacy is important. Student Task Manager:

  • ✓ Does not collect any personal information
  • ✓ Does not track your activity
  • ✓ Does not use any external services
  • ✓ Does not require authentication
  • ✓ Keeps all data on your local device
